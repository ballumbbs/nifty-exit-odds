Where the prices come from

  1. A GitHub Actions workflow in this repository runs every 5 minutes, Monday to Friday, 09:15–15:30 IST.
  2. It signs in to the Groww Trade API with the TOTP token and secret saved as repository secrets, reads the Nifty option chain and saves data/latest.json.
  3. Until those secrets are added, it publishes made-up demo prices and this page says so.
  4. The scanner only reads prices. It contains no code that can place, change or cancel an order.

How to read this. Each option's own price tells us how much movement the market expects. The page simulates 4,000 possible Nifty paths with that volatility, re-prices the option every 5 minutes, and counts which exit comes first. With your expected move at 0 these are the market's odds, not a forecast, and the average result usually comes out slightly negative: that gap is the cost of buying options without an edge. Put in the move you expect to see how much edge your plan needs. Weekends and holidays are not counted, gaps past a stop can make losses bigger, and a high "target hit" chance often comes with a small target or a wide stop.
